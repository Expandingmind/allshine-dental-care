# Allshine Dental Care

Marketing website for Allshine Dental Care. Built with Next.js + Tailwind, bilingual (English / Spanish), deployed on Vercel.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Pushed to `main` auto-deploys to Vercel.

## Replacing placeholder content

All copy lives in `src/lib/i18n/en.ts` and `src/lib/i18n/es.ts`. Images live in `public/`.

Update `src/lib/site-config.ts` with the real address, phone, hours, and booking URL.
